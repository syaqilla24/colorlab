========================================
COLOR LEARN - PANDUAN INSTALASI CEPAT
========================================

1. BUAT PROJECT BARU
   npm create vite@latest color-learn -- --template react-ts
   cd color-learn

2. INSTALL DEPENDENCIES
   npm install react-router@7.13.0 motion@12.23.24 lucide-react@0.487.0
   npm install tailwindcss@4.1.12 @tailwindcss/vite@4.1.12

3. COPY FILES
   - Copy folder 'src/' dari ZIP ini ke project Anda
   - Ganti semua isi folder src/

4. SETUP TAILWIND
   Buat file src/styles/theme.css:
   @import "tailwindcss";

5. UPDATE main.tsx
   import './styles/theme.css'

6. JALANKAN
   npm run dev
